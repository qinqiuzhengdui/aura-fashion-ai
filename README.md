# 服装灵感企划设计网页平台 (Fashion AI Inspiration Studio)

本项目是一个面向服装设计师、企划买手和时尚创意总监的 **AI 驱动端到端灵感企划设计平台**。它旨在将人工智能的强大能力融入到服装设计的企划阶段，提供从灵感收集、图片筛选、多视角生成到企划文案及最终文档输出的一站式工作流。

## 项目功能概述

1. **AI 智能对话与企划设计**：接入大语言模型，与用户进行自然语言交互，理解企划意图，并在全流程中提供辅助和文案生成。
2. **潮流资讯图库检索与筛选**：根据用户的具体要求，智能搜索各大潮流品牌服饰的高质量图片，并提供侧边栏交互界面供用户筛选最符合企划方向的图片。
3. **多维度关键图片生成**：结合用户的提示词和已筛选的图片，通过图像生成模型从不同视角、工艺、面料等多方面生成拓展图片。
4. **企划特征多模态提炼**：综合被筛选的图片与用户的文字描述，深入提取企划的详细特征与信息，进行补充、提炼与重组。
5. **智能文档与 PPT 生成**：将所有图片、精炼后的企划信息与用户要求结合，自动生成排版精美的文档及演示文稿（PPT）。

## 技术栈 (Tech Stack)

* **前端核心框架**：HTML5, CSS3, 纯原生 JavaScript (Vanilla JS)。
* **样式设计**：采用现代化的 CSS 规范，支持深色模式 (Dark Mode)，实现玻璃拟物化 (Glassmorphism)、平滑微交互动画以及全响应式布局。
* **背景与多媒体**：采用高端时尚动态视频（如“超高奢时尚。一位优雅女模特身着极简立体剪裁米白.mp4”）作为登录页面的视觉重心。

## 调用的 AI API 模型 (AI API Models Used)

本项目深度集成了多种前沿的 AI 大模型 API 以支撑核心业务流：

1. **核心对话与文本生成大模型 (LLMs)** 
   * **适用场景**：理解用户对话、提取企划设计关键要素、提炼企划文案、生成 PPT 文案大纲。
   * **推荐模型**：Google Gemini 1.5 Pro / Flash, OpenAI GPT-4o 等具备高逻辑性和多轮对话能力的模型。

2. **视觉图像生成大模型 (Vision Generation Models)**
   * **适用场景**：根据用户提示词及筛选的参考图，多方向分析企划，进行图像拓展、款式变换及多视角渲染。
   * **推荐模型**：Midjourney API, Stable Diffusion XL (SDXL) / Stable Cascade, 或 DALL·E 3。可结合 ControlNet 等技术保障服装结构和风格的落地一致性。

3. **视觉理解与多模态大模型 (VLMs - Vision-Language Models)**
   * **适用场景**：解析用户筛选的图片，从视觉层面提取色彩、面料、剪裁等专业信息，将其与大纲结合。
   * **推荐模型**：Gemini 1.5 Pro Vision, GPT-4V。

## 开发与运行

1. 克隆或下载本项目至本地。
2. **快速启动（推荐）**：双击运行根目录下的 `start_demo.bat` 脚本（Windows）。该脚本将一键自动安装依赖、启动 FastAPI 后端接口、挂载前端页面，并自动在浏览器中打开演示环境。
3. **手动启动**：
   ```bash
   pip install fastapi uvicorn pydantic
   python -m uvicorn backend.app:app --host 0.0.0.0 --port 8080
   ```
   然后访问 `http://localhost:8080`。
